ทำงาน Real-time ผ่าน Web Browser ทันที:

เมื่อเชื่อมต่อ Firebase ข้อมูลใบเสนอราคาจะซิงค์อัตโนมัติแบบ Real-time ให้ทีมทุกคนเห็นพร้อมกันทันที ไม่ต้องมีเซิร์ฟเวอร์

พร้อมเชื่อมต่ออัตโนมัติ

วิธีรับ Firebase Config ฟรี (1 นาที):

1. เข้า console.firebase.google.com และสร้างโปรเจกต์ใหม่

2. ไปที่ Project Settings > Your Apps > กดเพิ่ม Web App (</>)

3. คัดลอกข้อความในส่วน const firebaseConfig = { ... } มาวางในช่องด้านบนนี้

4. ไปที่เมนู Firestore Database แล้วกดสร้างฐานข้อมูล (เลือก Test Mode)

เชื่อมต่อระบบกับ Google Sheets หรือ Webhook เพื่อบันทึกประวัติการเสนอราคาลงตาราง Excel อัตโนมัติ

วิธีนำ Script ไปติดตั้งใน Google Sheets:

1. คัดลอกโค้ดจากไฟล์ google_apps_script.gs ในโฟลเดอร์นี้

2. เปิด Google Sheet > ส่วนขยาย (Extensions) > Apps Script > วางโค้ดและกด Deploy เป็น Web App

3. คัดลอก Web App URL มาใส่ในช่องด้านบนนี้
